# 分诊标签

将标准分诊角色映射为以下 GitHub 标签字符串。

| 角色 | 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 需要维护者评估 |
| needs-info | needs-info | 等待更多信息 |
| ready-for-agent | ready-for-agent | 规格完整，可由智能体实现 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不予处理 |

技能提到标准角色时，使用这些字符串。
标签描述就绪状态，不覆盖笔记库的审批规则。
本文件只记录术语，不会创建 GitHub 标签。
