# Bun 工程工具迁移

本阶段落实已批准的 [Bun + TypeScript 迁移范围](https://github.com/benjamin-qhy/personal-life-os/issues/3) 与 [实施顺序及验收](https://github.com/benjamin-qhy/personal-life-os/issues/6)。产品为 Personal Life OS，开发者为秋水（qiushui）。

## 已迁移

六个 Python 工具已用同名 TypeScript 入口替代：模板构建、模板验证、归档恢复验证、发行保护测试、阅读计划生成、章节拆分。四个 JavaScript 验证脚本也已改为 TypeScript：应用、助手工作流、Brain 浏览器交互、仪表盘浏览器交互。

Bun 负责维护工具、测试及构建，版本锁定为 1.3.14。浏览器合成测试继续使用 Playwright 与 Chromium。Bun/ACP 与浏览器脚本分别进行严格类型检查，避免混用不同宿主的全局类型。没有新增常驻服务。

CI 安装锁定依赖并禁止依赖安装脚本，执行类型检查、合成测试、应用契约、浏览器交互、独立候选构建与 ZIP 恢复验证。此处是 CI 配置更新，本机验证结果不等于 GitHub Actions 已运行通过。

## 行为及保护

- 阅读计划保留 1189 章、正典/年代顺序、分日和跳过星期参数；支持中文说明并拒绝非法日期、非正整数天数和全周跳过。
- 拆分器支持中文书名，保留路径、机器字段、筛选、导航与默认覆盖语义。章节回链按实际当前文件夹排除，修复旧固定目录条件。
- 构建继续使用私有临时目录、经过审阅的默认值、设置白名单、示例过滤及标准空看板；拒绝目标重叠、符号链接、既存候选与归档。
- 补齐阅读子目录大小写变体的私有内容过滤。路径键采用保守 Unicode 无大小写折叠与 NFC；包括 `ß/SS` 冲突。
- ZIP 检查路径、数量/展开大小、文件类型、CRC、全包 SHA256 和精确嵌入清单，临时恢复结束后删除。目录记录的异常 CRC/内容也拒绝。
- 发行验证先检查文件类型，再读取设置；发现本机凭据时跳过正文扫描，不回显匹配内容。
- 模板包只保留独立阅读工具和发行说明；维护源码、依赖、测试、凭据、会话和开发记录不进入包。三份 AGENTS 引用的工程规则文档保留以避免断链。
- 在发行默认目录补充 `CLAUDE.md` 导入入口，保留源码根目录此前移除该文件的开发配置；本机 `.obsidian` 没有修改。

## 验收记录

2026-10-04，第一份完整候选通过 164 项发行检查，204 个文件完成新旧恢复器交叉验证。旧模板验证器的内容与配置检查全部通过；仅其要求包内带旧维护验证器的两项不再适用，新的验证器从源码仓库执行对应应用门槛。

阅读工具与旧 Python 在合成数据上对照：两种顺序的章节与日期一致，拆分后的路径、链接和机器字段一致。应用验证保留 59 项行为断言，助手验证保留 16 个工作流。Brain 和仪表盘的真实 Chrome 合成测试均通过；旧仪表盘测试依赖英文月份，现将合成环境显式设为 `en-US`，后续中文版界面验收再同步中文断言。

`--without-reading` 变体仍被应用契约拒绝，因此没有生成该变体候选。后续迁移第一方插件时修复其对阅读模块的固定依赖；不放宽门槛来制造通过结果。

最终复测：66 项自动化测试、两组严格类型检查、59 项应用断言、16 个助手工作流和两套真实 Chrome 合成交互全部通过。最终候选通过 170 项发行检查，204 个文件恢复摘要一致。候选路径为 `/private/tmp/personal-life-os-bun-20261004-01/Personal-Life-OS-bun-final`，ZIP 的 SHA256 为 `f225220abf094f183052819760e2c55052e6bbd845bad12d9da893f6cb06a9fa`。这仍是工具迁移验证包，不是完整中文版发行版。
